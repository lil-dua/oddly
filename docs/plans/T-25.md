# Kế hoạch: CI GitHub Actions — test shared, build Android (R8), build iOS (T-25)

## Mục tiêu
Mỗi lần push/PR, GitHub Actions tự chạy: test `sharedLogic` trên JVM và Kotlin/Native, Android lint, build Android
release có R8 (không ký), build iOS cho simulator (kèm biên dịch target UI test). UI test emulator/XCUITest có
workflow riêng, chỉ chạy thủ công. Không đổi app, hành vi, toolchain hay dependency.

## Rủi ro & giả định
- **Label `macos-26` / Xcode trên runner**: giả định image macOS 26 GA và có Xcode 26.x. Nếu job iOS báo không tìm thấy runner hoặc Xcode
  quá cũ: đổi `runs-on` sang `macos-15` (hoặc `macos-latest`) và đặt `XCODE_VERSION` thành bản 16.x/26.x có trên image
  (danh sách ở repo `actions/runner-images`). Swift 5 + iOS 17 build được trên Xcode 16+.
- **JDK 25 trên CI**: nếu Gradle/AGP/Kotlin lỗi riêng trên Temurin 25 → đổi `java-version: 21`.
- **KMP trên Linux**: cấu hình `sharedLogic` có target iOS trên Ubuntu chỉ sinh cảnh báo "disabled targets", không tải Kotlin/Native macOS.
  Nếu job android lỗi vì điều này → thêm `kotlin.native.ignoreDisabledTargets=true` qua `-P` trong workflow (không sửa `gradle.properties`), hoặc chuyển host test sang job macOS.
- **Configuration cache trên CI**: `setup-gradle` không lưu config cache khi thiếu encryption key — chỉ chậm hơn, không lỗi.
- **Gradle trong build phase Xcode** cần `JAVA_HOME`: `setup-java` export cho mọi bước sau; nếu Xcode phase không thấy → export tường minh trong bước xcodebuild.
- **Lint**: số error chưa biết; baseline có thể ẩn bug thật — dev liệt kê error trong Dev notes để đưa backlog.
- **Không build iOS Release** trên CI: lỗi chỉ xuất hiện khi tắt `#if DEBUG` (UITestHooks) sẽ không bị bắt — QA khi Archive.
- **Emulator API 36 trên GitHub**: android-emulator-runner hỗ trợ, nhưng có thể chậm/flaky; vì chỉ chạy thủ công nên không chặn ai.
