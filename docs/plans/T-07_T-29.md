## Mục tiêu
1. **Android, system bar theo theme của app:** ở theme Sáng, icon status bar / navigation bar phải tối (nhìn thấy được). Ở theme Tối, icon sáng. Chế độ Hệ thống đi theo dark mode của máy, kể cả khi đổi trong lúc app đang mở. Đổi theme trong Settings thì cập nhật ngay, không cần mở lại app.
2. **Thẻ chia sẻ (S18) đọc được ở theme Sáng, cả hai nền tảng:** thẻ luôn tối (nền `OddlyColors.Background` + gradient tím). Chữ trên thẻ dùng palette tối bất kể theme đang chọn, cho cả bản xem trước lẫn ảnh PNG xuất ra. Ảnh xuất được flatten lên đúng màu nền của thẻ.
3. **Android chỉ còn một lớp splash:** dùng `androidx.core:core-splashscreen` (`installSplashScreen`) với nền `#07070C` + icon app trên mọi API 24+. Bỏ màn splash Compose S01 (`SplashScreen.kt`, `Destination.Splash`), để app mở thẳng vào Home (người dùng cũ) hoặc Onboarding (lần đầu).
4. Luật "theme nào thì tối" (`ThemeMode` + dark mode hệ thống) đặt ở `sharedLogic`, có unit test. Hai nền tảng gọi chung, không còn mỗi bên một `when`/`switch`.
