## Kế hoạch test (cho tester)
**Unit test** (`sharedLogic/src/commonTest`, tên backtick không dấu phẩy):
- `OddlyRepositoryTest`:
  - `rollover on the same day returns null` — state có `dailyChallenge` = `TODAY` với id seed thật.
  - `rollover to a new day picks a new challenge and keeps completions` — state ngày `daysAgo(1)`, có completions/profile/skippedCount; kết quả `dailyChallenge.date == TODAY`, completions/profile/skippedCount y nguyên.
  - `rollover does not hand back a challenge just completed` — completion hôm qua cho id X, rollover sang TODAY không trả X (dựa cooldown của `ChallengeSelector`; dùng nhiều seed `Random(n)` để chắc).
  - `rollover to an earlier day re-resolves` — `dailyChallenge` ở `daysAgo(-1)` (ngày mai), rollover về TODAY → không null, ngày TODAY.
  - `rollover replaces a pick that is no longer in the library` — cùng ngày, id không tồn tại → không null.
- `DailyChallengeRulesTest`:
  - `completing when the daily challenge is from yesterday is rejected as day changed` — `dailyChallenge` = `daysAgo(1)`, `now` = TODAY 00:10 → `Rejected(DAY_CHANGED)`, state không đổi.
